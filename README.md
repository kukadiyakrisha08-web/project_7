## 📖 About The Project

**Python Utility Toolkit** is a menu-driven Python application that combines multiple useful Python concepts into one project.

The project demonstrates the use of:

* 📅 `datetime`
* ⏱️ `time`
* 🎲 `random`
* 🆔 `uuid`
* 🧮 `math`
* 📁 File Handling
* 📦 Custom Python Modules
* 🔍 Module Attribute Exploration using `dir()`

The user can select different operations from the main menu and perform tasks interactively.

---

## ✨ Features

### 📅 1. Datetime & Time Operations

Perform different date and time operations:

* 🕒 Display Current Date and Time
* 📆 Format Date and Time
* ⏱️ Simple Stopwatch
* ⏳ Countdown Timer

---

### 🧮 2. Mathematical Operations

The custom math module provides:

* 🔢 Calculate Factorial
* 💰 Calculate Compound Interest
* 📐 Trigonometric Calculations

  * `sin()`
  * `cos()`
  * `tan()`
* ⭕ Calculate Area of a Circle

---

### 🎲 3. Random Data Generation

Generate random data using Python's `random` module:

* Random Number
* Random Programming Language Choice

Example choices:

```text
Python
Java
C++
```

---

### 🆔 4. UUID Generation

Generate a unique identifier using:

```python
uuid.uuid4()
```

---

### 📁 5. File Operations

The project includes a custom `file_module.py` for file handling.

Available operations:

* ✍️ Write Data to File
* 📖 Read File Data
* ➕ Append Data to File

All file operations are performed using:

```text
data.txt
```

---

### 🔍 6. Module Attribute Explorer

Explore the attributes and functions available inside the Python `random` module using:

```python
dir(random)
```
